# 发货政策

<p class="ab-meta">结构参考 [BitTopup Shipping Policy](https://bittopup.com/bittopup_shipping_policy.html) · 条款按 AceBase Demo 改写</p>

AceBase 以 **数字交付** 为主（直充到账、卡密/CDK 发送）。无实体快递（刀类周边 Demo 除外，正式发货以客服确认为准）。

## 发货方式

| 类型 | 方式 |
| --- | --- |
| 游戏直充 | 付款确认后充入指定账号 |
| 卡密 / PIN / CDK | 通过 Crisp / 邮件 / 客服渠道发送 |

详见：[发货与到账](../shop/shipping-and-delivery.md)

## 区域与适用性

数字商品可跨地区咨询，但请确认 **区服 / 国家适用性**（买错区可能无法使用）。

## 费用

数字交付 **不收取运费**。

## 联系

发货进度请走 [联系我们](contact.md) 或下单渠道。

!!! note "Demo"
    正式 SLA（到账时效承诺）上线前由客服口头/确认单约定。
