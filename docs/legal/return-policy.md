# 退款与退货

<p class="ab-meta">结构参考 [BitTopup Return Policy](https://bittopup.com/bittopup_return_policy.html) · 条款按 AceBase Demo 改写</p>

数字商品（直充 / 卡密）一经交付，通常 **不可退**。以下为示意规则，正式版以客服确认单为准。

## 退款（示意）

在下列情形下，可申请审核（不保证一定通过）：

- 商品存在可证实的缺陷或故障，且 **非用户原因**  
- 自购买日起 **14 天内** 提出申请  
- 审核通过后，退款一般退回原支付方式（示意时效：约 **7 个工作日**）

## 退货（示意）

数字商品即时交付，**原则上不接受退货**。例外示意：

- 可证明卡密 **无法使用**，且在购买后 14 天内主张  
- 卡密 **尚未兑换 / 使用**

## 虚拟商品特别说明

- 直充类一旦记入指定账号，视为已消费，通常 **不可撤回**  
- 完成付款即表示理解数字商品一经交付难以退回  
- 已交付的 PIN / 虚拟物品，除证实缺陷外，一般 **不予退款**

## 联系

退款相关请通过 [联系我们](contact.md) / [支持](support.md)，并附订单关键词与凭证。
