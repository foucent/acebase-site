# 支持

我们协助处理账号、订单与产品使用相关问题。

## 我们可以帮你什么

- **下单与付款**：如何报价、付款备注、对账  
- **到账异常**：未到账、错区、错号（多数直充不可冲正，先核对 ID）  
- **产品说明**：面额含义、区服限制、兑换提示  
- **反馈建议**：页面错误、体验问题  

## 怎么联系

请走 [联系我们](contact.md) 或 [如何下单](../shop/how-to-order.md)。尽量附上订单关键词与截图。
