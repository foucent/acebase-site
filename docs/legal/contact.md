# 联系我们

需要报价、催单或反馈时，请优先使用站内渠道。

## 推荐渠道

| 方式 | 说明 |
| --- | --- |
| **在线咨询** | 下单与进度查询首选，见 [如何下单](../shop/how-to-order.md) |
| **站内 Crisp** | 右下角聊天组件（若已启用） |

## 发消息时请带上

- 商品名 / 面额  
- 区服与账号字段（Player ID / UID / Zone ID 等）  
- 付款偏好与订单关键词
