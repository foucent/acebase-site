## 开始之前 {: #before }

下单之前先弄清四件事，剩下的交给客服。

- **不用注册，也不用购物车。** 本站没有会员系统，也没有需要登录的账号 —— 看到合适的价格，点卡片上的「查询实时价格」就能开始。
- **全站以美元（USD）计价。** 页面上标出的金额都已经换算好，不显示其他币种，也没有币种切换器。
- **页面上的价格是参考价。** 价格随汇率与渠道波动，所以每张卡片都写着「报价以在线咨询为准」—— 客服给出的实时报价才是成交价。
- **把需求想具体。** 想清楚要买哪款游戏或哪个平台、哪一档位或哪个面额，以及所在区服或地区；礼品卡的地区要跟账号地区对得上。

## 购买流程 {: #steps }

一次咨询走完四步，全程都在同一个聊天窗口里。

### 第一步：在页面上挑档位 {: #step-1 }

价格页上的每张卡片收起时露出两个档位，点「展开」可以看到全部档位。列出来的都是参考价，先挑一个大致合适的即可，不必自己换算。

### 第二步：把需求发给在线客服 {: #step-2 }

点卡片上的「查询实时价格」，或者用页面右下角的聊天按钮，把商品、档位和区服（礼品卡则是地区）发给客服。

代储类商品通常只需提供游戏 UID 或游戏账号所在区服等身份信息用于到账，具体以在线客服引导为准。**任何情况下都不需要提供账号密码。**

### 第三步：确认报价，用 Wise 付款 {: #step-3 }

客服确认库存与实时报价后，会给出 Wise 收款信息。按客服给的金额转账，并以订单号作为备注；转好后把付款信息发回同一个聊天窗口。

### 第四步：到账与收货 {: #step-4 }

- **代储与充值**：发放到对应的游戏账号，进度客服会在聊天里同步。
- **礼品卡与卡密**：在支付成功后自动发放，通常几分钟内到账，可在订单详情中查看兑换码；使用之前请确认账号地区与卡密地区一致。

## 价格与费用 {: #fees }

- **计价货币**：全站美元（USD），金额已换算好，不显示其他币种。
- **参考价与应付金额**：页面标的是参考价，客服会在下单前把应付金额说清楚，确认之后再付款 —— 客服确认的金额就是应付金额。
- **会员费与订阅费**：本站没有会员费与订阅费。
- **价格为什么会变**：页面上「更新于」的日期就是最近一次刷新的时间；档位金额会随汇率重算，所以同一个档位在不同时间看到的价格可能不一样。

## 常见问题 {: #faq }

**需要注册账号或者登录吗？**

不用。本站没有会员系统，也没有购物车，直接在线咨询即可。

**为什么价格和我上次看到的不一样？**

参考价随汇率与渠道波动。页面上的价格是参考价，以客服给出的实时报价为准。

**可以用人民币或者其他货币付款吗？**

页面上统一以美元标价。实际付款的渠道与币种，客服会在在线咨询里说明。

**代储需要提供什么信息？**

通常只需提供游戏 UID 或游戏账号所在区服等身份信息用于到账，具体以在线客服引导为准。任何情况下都不需要提供账号密码。

**付款之后多久能到？**

代储与充值在客服确认报价后安排到账；卡密类在支付成功后自动发放，通常几分钟内到账。具体以在线客服引导为准。

**礼品卡的地区要注意什么？**

各品牌可购买地区以页面标注为准（如美国 / 日本 / 欧洲等）。购买前请确认您的账号地区与礼品卡地区一致，地区不符可能导致无法兑换。

**遇到问题找谁？**

回到原来那次在线咨询，把订单号发给当时那位客服，说明遇到的情况即可。

**页面上的价格多久更新一次？**

页面上「更新于」的日期就是最近一次刷新的时间。档位金额会随汇率重算，所以同一个档位在不同时间看到的价格可能不一样。
