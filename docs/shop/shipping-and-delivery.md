# 发货与到账

## 交付类型

| 类型 | 我们做什么 | 你需要提供 |
| --- | --- | --- |
| **游戏直充** | 付款确认后按面额充入指定账号 | 区服、Player ID / 约定登录方式 |
| **卡密 / PIN / CDK** | 发送卡密与兑换指引 | 接收渠道（Crisp / Email 等） |
| **咨询类** | 商品与下单指引 | 预算与使用场景 |

---

!!! note "追踪"
    数字单没有快递单号。进度以 **在线咨询** 回复为准；异常请带上付款凭证与订单关键词。

---

## 异常怎么处理

1. **未到账**：先核对区服与 ID，再联系客服并附付款截图。  
2. **错区 / 错号**：多数无法冲正；以事前核对为主。  
3. **重复付款**：保留两笔凭证，由客服核对后退款或改充（视情况）。
