# 如何下单

参考 [MyGear Guide · Shop](https://guide.mygear.top/) 的下单分区结构。AceBase 当前以 **充值比价咨询、加速器咨询** 为主；正式下单请走 **WhatsApp** 或站内 **在线客服**。

## 下单步骤

### 1. 发来需求

请一次性说清：

```text
游戏 / 区服：
面额或套餐：
账号信息（Player ID / 登录方式，按商品要求）：
付款偏好（Wise / 其它）：
备注：
```

### 2. 确认报价

客服回复 **含手续/到账说明的总价** 与预计时效。库存或区服不匹配时会提前说明并帮你改单。

### 3. 付款

按确认金额支付（推荐 Wise）。请备注 **订单关键词 / 昵称**，便于对账。

### 4. 到账或对接

付款确认后按 [发货与到账](shipping-and-delivery.md) 完成直充或发送卡密。

!!! tip "提示"
    商品页价格只作参考；**最终以客服报价为准**。高风险渠道请勿自行尝试。
