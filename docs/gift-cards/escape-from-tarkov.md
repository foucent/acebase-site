# Escape from Tarkov

Hardcore realistic first-person action RPG / simulator with MMO elements and a progressing story. In the ongoing conflict around Norvinsk, play as a USEC or BEAR PMC — loot, fight, and extract from Tarkov in extraction-shooter gameplay. SEAGM has no dedicated Tarkov card; common top-up path is a **Steam Wallet (USD)** code.

- High-difficulty PvPvE extraction shooter
- Heavy gear loss and inventory pressure

## How to redeem?

1. Sign in to Steam
2. Open [Redeem a Steam Wallet Code](https://store.steampowered.com/account/redeemwalletcode)
3. Choose Redeem a Steam Gift Card or Wallet Code
4. Paste the code from SEAGM **My Cards** and confirm
5. Once credited, buy games / DLC / in-app items on Steam
