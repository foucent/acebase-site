## How to redeem?

1. Sign in to Steam
2. Open [Redeem a Steam Wallet Code](https://store.steampowered.com/account/redeemwalletcode)
3. Choose Redeem a Steam Gift Card or Wallet Code
4. Paste the code from SEAGM **My Cards** and confirm
5. Once credited, buy games / DLC / in-app items on Steam

---

## Purchase & delivery (SEAGM example)

1. Open [Steam Wallet Code (USD)](https://www.seagm.com/zh-hk/steam-wallet-card-code-global)
2. Choose a denomination and pay
3. Check **My Cards** in your account
4. Reveal the code and redeem on Steam
